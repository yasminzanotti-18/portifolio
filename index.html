Projeto em destaque

AgriFarm

Gerenciamento inteligente de ração nas fazendas

Sistema webAplicativo mobileSensores IoTAnálise de dados

Projeto desenvolvido durante minha formação técnica no SENAI: um sistema web e um aplicativo mobile para gerenciar a alimentação animal nas fazendas, com sensores IoT e análise inteligente de dados para acompanhar o consumo de ração, controlar estoques, identificar desperdícios e gerar relatórios que apoiam a tomada de decisão.

01

O desafio

Fazendas perdem ração por falta de controle: consumo difícil de medir, estoque sem previsão e desperdício percebido tarde demais.

02

A solução

Sistema web e aplicativo mobile integrados a sensores IoT, que registram o consumo, controlam o estoque e mostram relatórios claros para o produtor decidir.

03

Meu papel

Levantamento de requisitos, modelagem dos dados, prototipação das telas e testes das funcionalidades junto ao restante do grupo.
